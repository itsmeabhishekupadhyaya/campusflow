# Prerequisites
## Required Software
- Node.js (LTS)
- Git
- Visual Studio Code
----------------------------------------------------------------------
# Recommended VS Code Extensions

## Install the following recommended VS Code extensions:

- ESLint
- Prettier
- GitLens
- Error Lens
- Material Icon Theme
-----------------------------------------------------------------------------
# Clone Repository
git clone https://github.com/itsmeabhishekupadhyaya/enterprise-work-management.git
--------------------------------------------------------------------------------------
# Install Dependencies
```bash
git clone https://github.com/itsmeabhishekupadhyaya/enterprise-work-management.git

cd enterprise-work-management/client

npm install
```
-----------------------------------------------------------------------
 # Run Project
```bash
npm run dev
```
--------------------------------------------------------------------------
# Troubleshooting
## Problem
git : The term 'git' is not recognized.
## Cause
Git is either not installed or not available in the system PATH.
## Solution
1. Install Git.
2. Restart VS Code.
3. Verify using
```bash
git --version
```
